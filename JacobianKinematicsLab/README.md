# JacobianKinematicsLab 硬點運動學

將靜態 XYZ 硬點轉成雙 A 臂懸吊，聯立求解四輪輪跳、前齒條轉向、轉向拉桿，以及剛性推桿與搖臂的運動。工具可整個資料夾單獨複製並啟動，使用 Python 3.10+、Tkinter 和 NumPy。

## 啟動與匯入

1. 在 Windows 雙擊 [Start-JacobianKinematicsLab.bat](Start-JacobianKinematicsLab.bat)。也可在工具資料夾的上一層執行以下指令。
2. 啟動時會載入 StaticWireframe 基準車輛的 [硬點 CSV](examples/hardpoints.csv)。
3. 按「匯入 CSV」開啟其他硬點檔或已存檔的專案。主視窗顯示目前檔名，`*` 表示有未存檔的變更。
4. 開啟「硬點與輪胎設定」，可修改硬點座標、輪胎寬度、半徑與靜態定位。再到「輪跳與轉向」設定行程，按「開始求解」。
5. 在 3D 視圖點選節點或桿件，再切到對應結果頁查看曲線。左側顯示曲線，右側顯示表格。可拖曳中間的分隔線調整寬度，或橫向捲動表格查看其餘欄位。點擊曲線可定位樣本。CSV 可一次匯出全部節點和桿件的歷程，以及目前選取的兩點運動比。

```powershell
python -m pip install -r JacobianKinematicsLab/requirements.txt
python -m JacobianKinematicsLab
```

硬點表使用 UTF-8 CSV。表頭為 `name,x_m,y_m,z_m` 或 `name,x_mm,y_mm,z_mm`。也接受以 `point` 表示點名，並可加 `corner` 欄組合輪位與點名。每個點名須唯一。

按「存檔」或 `Ctrl+S` 會更新目前匯入的 CSV。從內建硬點開始時，第一次存檔會請你選擇新的 CSV 檔名。專案將推桿接法、輪胎尺寸及定位、輪跳與轉向設定、變形元件一起存在 CSV 的 `jacobian_project` 欄，重新匯入時會還原。切換檔案或關閉視窗前，程式會詢問如何處理已套用而尚未存檔的變更。

## 3D 運動視圖

在「3D 運動」頁可先檢查匯入的靜態硬點與桿件連接。求解完成後可使用「播放」、「暫停」與「回到起點」，也能調整播放速度、開啟「循環」，或拖曳時間軸停在指定樣本。3D 視圖依該樣本的 XYZ 座標畫出各節點，並依機構的桿件定義連接端點。

- 左鍵拖曳可旋轉，右鍵或中鍵拖曳可平移。滑鼠滾輪以游標處為中心縮放。
- 使用「3D 斜視」、「前視」、「側視」或「上視」核對不同方向的幾何。「重設視角」可回到目前視角的初始縮放與位置。
- 灰色方框是固定點，青綠色圓點是活動點，淡藍色線段是目前桿件。可勾選「靜態參考」疊加靜態姿態虛線，或勾選「節點名稱」顯示點名。
- 齒條、轉向拉桿與推桿以不同顏色呈現，可用視圖左上方的圖例辨識。
- 預設可各選一個節點和一根桿件。勾選「比較模式」後，求解前就可在 3D 視圖各點選兩個節點和兩根桿件。A 以琥珀色標示，B 以紫色標示。再點一次可取消選取。點選同類的第三個項目時，會保留最近選取的兩個。取消勾選會各保留 A。
- 3D 視圖下方會列出所選名稱，並顯示最近選取類別的節點 XYZ 或桿長。求解後，節點會加顯示 ΔX、ΔY、ΔZ。按「查看曲線」可開啟該類別的結果。

曲線、結果表與 3D 視圖共用同一個時間樣本。點擊曲線或選取表格列會暫停播放並定位到對應樣本，切回 3D 即可檢視該時間的幾何。

「節點」與「桿件」頁可用 A、B 下拉選單更換 3D 選取項目，兩頁與 3D 共用「比較模式」。選好 A 和 B 後，兩筆資料會在同一張圖上使用相同的時間軸和單位，A 為實線、B 為虛線。右側表格會並排列出同一樣本的 A、B 數值。

有輪心 `WC` 的輪位會顯示半透明車輪，依求得的羊角姿態平移與轉動。求解器自動生成的輪向參考點只用於計算輪向曲線，節點清單、3D 視圖和節點 CSV 會省略這些內部點。

「硬點與輪胎設定」以 mm 列出 CSV 匯入的所有硬點。選取一列可在下方修改 XYZ，並依輪位設定輪胎尺寸與靜態 Toe、Camber。Toe 正值為內束，留空採 `FORWARD` 的水平輪向，沒有輪向標記時預設為 0°。Camber 正值為輪胎頂端朝外，預設為 0°。這兩個角度定義輪胎相對羊角的靜態安裝姿態，套用到 3D 車輪和懸吊特性。硬點與桿件的結果依其座標和約束求解。

### 桿件干涉

按「開始求解」後，工具會在各時間樣本比較實體桿件的 3D 中心線。兩條線段相交或距離在 0.01 mm 內時，會顯示桿件名稱及首次發生時間。共用接點與幾何輔助線會略過。點選時間軸上的「首處干涉」可切到第一處干涉的 3D 姿態。這項檢查以線段與時間樣本為基礎，實體外形的間隙取決於零件尺寸。

## 懸吊硬點與工況

車輛座標為 X 向前、Y 向左、Z 向上。硬點名稱前面加輪位 `FL_`、`FR_`、`RL_` 或 `RR_`，例如 `FL_RACK`。可對照[完整四輪範例 CSV](examples/hardpoints.csv)。

範例的 A 臂、輪心、齒條、轉向拉桿、推桿與搖臂已整理成硬點 CSV，來源參數保存在 [new/suspension_geometry.json](../new/suspension_geometry.json)。分析實車時可在硬點編輯器輸入量測座標，或匯入實車的硬點 CSV。

| 硬點後綴 | 定義 |
| --- | --- |
| `UCA_F`、`UCA_R`、`LCA_F`、`LCA_R` | 上、下 A 臂的前後車身固定點 |
| `UBJ`、`LBJ`、`WC` | 上下球接點與輪心，隨羊角運動 |
| `RACK`、`TOE` | 轉向拉桿內端與羊角外端。同一輪位須成對提供。前輪內端隨齒條移動，後輪內端固定在車身 |
| `PUSH_OUT` | 推桿外端，隨下 A 臂運動。接上 A 臂時改用 `PUSH_OUT_UCA`，接羊角時改用 `PUSH_OUT_UPRIGHT` |
| `PUSH_IN`、`ROCKER_A`、`ROCKER_B` | 推桿內端為搖臂活動點。兩個 `ROCKER` 點是車身固定鉸鏈的軸線定義，兩者須分開，且 `PUSH_IN` 須離開軸線 |
| `FORWARD` | 選填，以輪心指向此點作為靜態輪向。省略時採輪心前方 100 mm 的虛擬點 |

在「硬點與輪胎設定 → 推桿外端所屬剛體」可依輪位選擇上 A 臂、下 A 臂或羊角（Upright）。外端沿用硬點表的靜態 XYZ，可以偏離所選剛體的基準點或平面，求解時隨該剛體一起平移和轉動。套用後按「開始求解」，可在 3D 視圖播放並點選推桿查看結果。載入沒有專案設定的 CSV 時，預設接法由硬點名稱決定。

- 四輪輪心可各自設定 Z 行程。正值為上壓，負值為下垂。前齒條的輸入是沿軸的直線位移，單位為 mm。左右內端 `FR_RACK` 到 `FL_RACK` 定義齒條軸線，正值朝車輛左側。單輪前懸吊資料採 +Y 軸。轉向盤角度與齒條位移的換算需使用實車的轉向機構資料。
- 各輪與前齒條可分別選「往返」、「正弦」或「線性」。往返從零到輸入振幅再回零，正弦走完一個正負週期，線性等速從零移至輸入量。基準範例預設輪心上壓 +20 mm、21 個樣本及齒條 0 mm。「基準上壓 +20 mm」和「基準下垂 −30 mm」可把四輪行程切換至來源 JSON 的上壓或下垂設定。來源的轉向掃描角度用於 Suspension Geometry Lab，齒條的直線行程可在新工具另行輸入。
- 在「桿件」可選 `FL_WHEEL_HEADING`、`FR_WHEEL_HEADING` 等輪向參考線，方位角由車輛 +X 朝 +Y 為正。亦可查看 `FL_RACK-TOE`、`FL_PUSH_ROD` 等桿件的角度、角速度與角加速度。推桿兩端保持固定桿長，內端隨搖臂鉸鏈轉動。
- 基本懸吊 CSV 仍可匯入。若當輪只有 A 臂硬點與輪心，會維持靜態輪向。只含六個 A 臂硬點時，行程輸入控制上球接點的 Z。舊表的 `UFI`、`URI`、`LFI`、`LRI`、`wheel_center`、`ROD_IN`、`ROD_OUT` 可直接匯入。

## 變形元件

按「變形元件…」開啟編輯視窗，為避震器等元件輸入名稱及 A、B 端點在靜態姿態下的車輛 XYZ 座標（mm）。每端可獨立選擇車體或一支已定義的搖臂（FL、FR、RL、RR）。車體端固定在輸入的座標，搖臂端隨該搖臂繞鉸鏈軸轉動。再次開啟視窗，可從清單選取既有元件修改或移除。

元件的軸線由 A、B 端點連成，長度隨運動改變。套用並重新求解後，可在 3D 視圖選取元件，或在「桿件」頁查看「長度」與「軸向壓縮量」。壓縮量等於靜態長度減去當前長度，正值表示壓縮，負值表示伸長。

### 求解結果

設定「輪跳與轉向」並按「開始求解」後，在主分頁「避震器行程 → 求解結果」選擇要查看的避震器。曲線可切換壓縮量（mm）、壓縮速度（mm/s）與壓縮加速度（mm/s²），表格並排列出三項數值。選填避震器 B 時，可疊圖比較兩支元件。曲線與表格共用 3D 視圖的時間樣本。

壓縮速度及加速度為軸向壓縮量對時間的一、二階導數，由求得的端點位置、速度及加速度計算。壓縮速度為正時，避震器正在縮短。

### ROLL 與 HEAVE 行程掃描

在主分頁「避震器行程 → ROLL／HEAVE 掃描」選擇前軸或後軸及要查看的避震器。選擇 ROLL 或 HEAVE，設定掃描範圍與另一個量的固定值，再按「計算掃描」。所有輸入均以 mm 為單位，輪跳正值為上壓。

- **ROLL** 為左輪位移減右輪位移。輸入非負的掃描範圍，圖上會把同幅度的左側 ROLL（正位移差）和右側 ROLL（負位移差）疊在一起。
- ROLL 的表格會列出每支避震器在相同幅度下的「左右差距 (%)」，也可在「曲線」選單切換到百分比圖。以兩側伸縮量的絕對值為幅度，差距百分比等於幅度差的絕對值除以兩側平均幅度，再乘 100。兩側幅度皆接近零時顯示 0%。
- **HEAVE** 為左右輪位移和。左右輪位移分別為 `(HEAVE + ROLL) / 2`、`(HEAVE − ROLL) / 2`。另一車軸和齒條均維持零位移。
- 勾選「取絕對值（伸縮變化量）」會即時顯示壓縮量的絕對值。選填避震器 B 可在同一張圖比較兩支避震器，A 為實線，B 為虛線。

## 懸吊特性

### 單輪輪跳

載入含輪心 `WC` 的標準懸吊 CSV 後，開啟「懸吊特性 → 單輪輪跳」，選擇輪位、設定輪跳範圍，再按「計算掃描」。輪跳正值為上壓，其他輪位保持零輪跳。具有轉向拉桿的前輪可指定齒條下限和上限，圖表會比較下限、中點、上限三個固定位置。可將齒條上下限設成相同值以查看單一位置。後輪與沒有轉向拉桿的前輪只掃描輪跳，齒條保持零位移。掃描樣本有自己的橫軸及表格游標。

| 特性 | 定義 |
| --- | --- |
| 外傾角與 Camber gain | 外傾角以輪胎頂端朝外為正，靜態外傾取自輪胎設定。Camber gain 是固定齒條時外傾角對輪跳的 Jacobian 偏導數，單位為 °/mm |
| 前束角與 Bump steer | 前束以 toe-in 為正。Bump steer 為同一齒條位置下，當前前束角減去零輪跳的前束角。也可查看固定齒條時前束角對輪跳的偏導數 |
| 輪距 | 同軸左右輪心的 Y 向間距。需要同軸另一輪的 `WC` |
| 軸距 | 同側前後輪心的 X 向間距。需要同側另一軸的 `WC` |

### 前軸轉向

兩顆前輪均有 `WC`、`RACK`、`TOE` 時，在「前軸轉向」設定 Heave、Roll 及齒條範圍。Heave 為兩輪平均輪跳（mm），正值為上壓。Roll 以度表示，正值為左輪相對右輪上壓。左、右輪跳分別為 `Heave ± (靜態前輪距 / 2) × tan(Roll)`。掃描期間固定兩顆前輪的輪跳，後輪維持零輪跳。

左右前輪轉角以相同 Heave、Roll 下的齒條零位為基準，兩輪皆以向左為正。圖表可切換到包含靜態定位的絕對航向，或查看左輪轉角減右輪轉角。表格同時列出兩輪轉角、轉角差、阿克曼率與絕對航向。

阿克曼率採 `100 × (cot(|外輪轉角|) − cot(|內輪轉角|)) / (前輪距 / 軸距)`。理想阿克曼為 100%，平行轉向為 0%。直行、兩輪轉向相反或角度無法套用時留白。前輪距取靜態前輪心的 Y 向間距，軸距預設取前後軸輪心平均 X 的距離。只有前軸硬點時，可手動輸入軸距。

## 命令列自訂機構

非標準接法可從命令列用 `--hardpoints` 和 `--mechanism` 指定硬點 CSV 與機構 JSON。CSV 提供靜態座標，JSON 完整定義固定點、連接、剛體附著及驅動。JSON 內的點名須與 CSV 完全相同。

| JSON 欄位 | 用法 |
| --- | --- |
| `fixed` | 車身或地面固定點的名稱陣列 |
| `links` | 每條剛性距離約束包含 `name`、端點 `a`、端點 `b`，長度取自靜態硬點。可用 `constrained: false` 保留僅供顯示與輸出的參考線 |
| `attachments` | 選填。每項包含活動點 `point` 與三個非共線錨點 `a`、`b`、`c`。由其他約束維持錨點三角形的尺寸，附著點隨該剛體移動 |
| `drives` | 每項包含 `name`、`point`、`direction`，以指定方向上的投影相對靜態位置作為驅動座標 |
| 驅動的 `b` | 選填，用兩點 `point − b` 的相對位置投影，適用於保持某一方向的相對間距 |
| `amplitude_mm`、`profile` | 振幅以 mm 表示。 `pulse` 為平滑往返，`sine` 為完整正弦週期，`ramp` 為等速單程 |
| `locked` | 設為 `true` 時固定投影值，振幅保持零，可用於齒條導軌或限制相對方向 |
| `duration_s`、`samples` | 工況時間與樣本數，預設 2 秒、121 點 |

多點剛體可用足以確定其形狀的桿長約束組成。模型應給足約束與驅動，使每個移動座標在局部唯一。若起始姿態秩不足、桿長不相容、行程不可達或作動經過奇異姿態，求解會顯示原因及對應時間（適用時）。

## 結果與計算

| 項目 | CSV | 單位與定義 |
| --- | --- | --- |
| 節點 | `point_kinematics.csv` | 每個時間、每個點的 XYZ 絕對位置、速度、加速度與相對位移。相對位移欄位為 `dx_m`、`dy_m`、`dz_m`。CSV 採 m、m/s、m/s²，介面採 mm、mm/s、mm/s² |
| 桿件 | `rod_kinematics.csv` | 每條桿件從 A 指向 B 的方位角、仰角、與靜態方向的夾角（°），以及桿軸三軸角速度和角加速度（rad/s、rad/s²） |
| 兩點比較 | `motion_ratio.csv` | 所選點與投影方向、投影位移、切線率、有號運動比、理想機械利益與各樣本狀態 |

在「節點」的訊號下拉選單切換「位置」或「相對位移」。相對位移以該節點原始靜態 XYZ 為零點，分別計算 ΔX、ΔY、ΔZ。「相對位移」、「速度」和「加速度」的曲線及表格分別加列總位移、合速度和合加速度，均以三個分量的平方和開根號計算。

位置以靜態姿態為起點，逐步沿驅動歷程迭代解固定桿長與投影約束。速度使用同一個約束 Jacobian 解一階微分方程。加速度使用二階微分，並納入各桿件端點相對速度造成的曲率項。桿軸由兩端點決定，角速度與加速度描述軸線轉向。求桿件繞自身長軸的自旋需要額外姿態資訊。方位角在各段連續展開，桿軸鉛直的樣本留白。

兩點比較可各自指定量測方向，例如 `z`、`-y` 或 `1,0,2`。先把兩個點的虛位移分別投影成 `ds_in` 與 `ds_out`。運動比為 `ds_out / ds_in`，保留方向正負。理想機械利益依虛功關係為 `|ds_in / ds_out|`。兩者均無因次。

有多項驅動時，可沿實際時間歷程比較，也可選定一項驅動，以 Jacobian 求該驅動的局部偏導數並保持其他驅動座標固定。沿時間歷程比較時，往返端點的速度可能同時為零，此處留白。指定單項驅動可在同一姿態檢查虛位移比。分母投影為零的樣本留白，CSV `status` 欄記錄原因。
