Jacobian Method

SuspensionKinematicsLab starts with static hardpoints. It solves the geometry at each prescribed wheel and rack displacement, then differentiates the same constraints to find point velocities, accelerations, and local sensitivities.

Run an analysis

  1. Inspect the reference suspension in 3D motion. To open another study, use Import CSV / JSON at the bottom of the left settings panel.
  2. Use Hardpoints & tires to edit coordinates, tire dimensions, static toe and camber, and pushrod mounts. To study damper travel, use Deformable members to add a member and attach each endpoint to the chassis or to a defined rocker.
  3. Open Wheel travel & steering to set a duration, sample count, and motion profile for each wheel or rack drive, then choose Apply motion. Positive wheel travel is bump, meaning the wheel moves up relative to the chassis. Positive rack travel follows the axis from the right rack point toward the left one. A model with a single front rack point uses +Y.
  4. Choose Solve kinematics. Use the timeline, chart, or results table to inspect a sample and select points or rods in the 3D view to follow their motion.
  5. Use Download JSON or Download CSV project to resume a study later. Open Export results to download solved histories as CSV files.

Hardpoints and projects

The vehicle frame uses +X forward, +Y left, and +Z up. Use UTF-8 CSV with name,x_m,y_m,z_m or name,x_mm,y_mm,z_mm. Each name must be unique. A point column also works and can be paired with a corner column.

Prefix standard suspension hardpoint names with FL_, FR_, RL_, or RR_, for example FL_WC. Each included corner needs the four control arm pivots and both ball joints.

Hardpoint suffixRole
UCA_F, UCA_R, LCA_F, LCA_RUpper and lower control arm chassis pivots, front and rear.
UBJ, LBJ, WCUpper and lower ball joints and wheel center. If the wheel center is omitted, the travel drive acts on the upper ball joint.
RACK, TOEInner and outer tie rod endpoints. Provide them as a pair. Rear inner endpoints are fixed.
PUSH_OUT, PUSH_IN, ROCKER_A, ROCKER_BPushrod endpoints and the rocker hinge axis. The default outboard mount is the lower control arm. Use PUSH_OUT_UCA or PUSH_OUT_UPRIGHT for a different default.
FORWARDOptional wheel heading marker. Its position relative to WC defines the default heading. When omitted, the reference marker is placed forward of the wheel center.

For a direct-acting damper, provide a pushrod outboard point and a chassis-side PUSH_IN, and omit both ROCKER_A and ROCKER_B. The lab warns that it has created a deformable member and reports its travel under Dampers. Download the four-corner direct-acting example CSV.

Tire toe and camber in Hardpoints & tires set the static tire orientation relative to the upright. Positive toe is toe-in and positive camber tilts the top of the wheel outward. A blank toe field takes the horizontal heading from FORWARD, or zero degrees when no heading marker was supplied.

A project JSON stores hardpoints under points as names mapped to XYZ arrays in metres. The full format uses "version": 1 and adds tire setup, pushrod mounts, drive profiles, and deformable members. Deformable endpoints also use metres in JSON. A desktop project CSV stores settings in its jacobian_project column.

For a custom mechanism, use Import CSV / JSON to open a complete project JSON with a mechanism field, or select a hardpoint CSV and its matching mechanism JSON together.

The mechanism maps hardpoint names to fixed points, distance links, rigid attachments, and projected displacement drives. A link with constrained: false is available for display and measurement. A drive with locked: true holds its projection at the reference value. Its optional b field changes the projection from a single point to the separation between two points.

Mechanism constraints

The unknown vector q stacks the XYZ displacements of all moving points. A fixed point has zero displacement. The solver adds each displacement to the point’s reference position.

pi=pi,0+qi,q=[q1T⋯qnT]T \boldsymbol{p}_i=\boldsymbol{p}_{i,0}+\boldsymbol{q}_i, \qquad \boldsymbol{q}= \begin{bmatrix}\boldsymbol{q}_1^{\mathsf T}&\cdots&\boldsymbol{q}_n^{\mathsf T}\end{bmatrix}^{\mathsf T}

Rigid links

For a link from A to B, the current axis is r and the reference length is L. The normalized squared-distance residual is zero when the rod keeps its reference length.

r=pB−pA,L=∥pB,0−pA,0∥,Flink=r⋅r−L22L. \begin{aligned} \boldsymbol{r}&=\boldsymbol{p}_B-\boldsymbol{p}_A,\\ L&=\lVert\boldsymbol{p}_{B,0}-\boldsymbol{p}_{A,0}\rVert,\\ F_{\mathrm{link}}&=\frac{\boldsymbol{r}\cdot\boldsymbol{r}-L^2}{2L}. \end{aligned}

Differentiating this residual gives two three-coordinate blocks. Blocks for fixed points are dropped from the solved Jacobian.

∂Flink∂qA=−rTL,∂Flink∂qB=+rTL \frac{\partial F_{\mathrm{link}}}{\partial\boldsymbol{q}_A} =-\frac{\boldsymbol{r}^{\mathsf T}}{L}, \qquad \frac{\partial F_{\mathrm{link}}}{\partial\boldsymbol{q}_B} =+\frac{\boldsymbol{r}^{\mathsf T}}{L}

Rigid attachments

Three non-collinear anchors A, B, and C carry the marker M. The solver first finds the local coefficients a, b, and c from the reference geometry. It then keeps those coefficients fixed as the anchor vectors move. The cross-product term lets the marker sit out of the anchor plane.

e=pB−pA,f=pC−pA,E0=[e0 f0 e0×f0],pM,0−pA,0=E0[abc],Fattach=pM−pA−ae−bf−c(e×f). \begin{aligned} \boldsymbol{e}&=\boldsymbol{p}_B-\boldsymbol{p}_A,\qquad \boldsymbol{f}=\boldsymbol{p}_C-\boldsymbol{p}_A,\\ E_0&=[\boldsymbol{e}_0\ \boldsymbol{f}_0\ \boldsymbol{e}_0\times\boldsymbol{f}_0],\\ \boldsymbol{p}_{M,0}-\boldsymbol{p}_{A,0} &=E_0\begin{bmatrix}a\\b\\c\end{bmatrix},\\ \boldsymbol{F}_{\mathrm{attach}} &=\boldsymbol{p}_M-\boldsymbol{p}_A-a\boldsymbol{e}-b\boldsymbol{f}\\ &\quad-c(\boldsymbol{e}\times\boldsymbol{f}). \end{aligned}

Displacement drives

A drive uses a unit direction d and a prescribed scalar displacement u. When there is a second point Q, the drive measures the displacement of P relative to Q. A single-point drive omits the Q term.

Fdrive=d⋅(qP−qQ)−u(t) F_{\mathrm{drive}} =\boldsymbol{d}\cdot(\boldsymbol{q}_P-\boldsymbol{q}_Q)-u(t)

The solver stacks the link, attachment, and drive residuals into F. The matrix B places each drive input in its own residual row. At every trial pose, the solver evaluates J from the current link axes and attachment geometry.

F(q,t)=G(q)−Bu(t),Jij=∂Fi∂qj. \begin{aligned} \boldsymbol{F}(\boldsymbol{q},t)&=\boldsymbol{G}(\boldsymbol{q})-B\boldsymbol{u}(t),\\ J_{ij}&=\frac{\partial F_i}{\partial q_j}. \end{aligned}

Drive profiles

Let A be the signed amplitude in metres, T the duration in seconds, and ω = 2π/T. Write φ = ωt for the phase. The pulse reverses direction at half duration. The sine completes one cycle and the ramp moves at constant speed. The program evaluates displacement, speed, and acceleration analytically at each sample time.

Profileuu˙u¨PulseA2(1−cos⁡ϕ)Aω2sin⁡ϕAω22cos⁡ϕSineAsin⁡ϕAωcos⁡ϕ−Aω2sin⁡ϕRampAt/TA/T0 \begin{array}{c|ccc} \text{Profile} & u & \dot{u} & \ddot{u}\\ \hline \text{Pulse} & \tfrac{A}{2}(1-\cos\phi) & \tfrac{A\omega}{2}\sin\phi & \tfrac{A\omega^2}{2}\cos\phi\\ \text{Sine} & A\sin\phi & A\omega\cos\phi & -A\omega^2\sin\phi\\ \text{Ramp} & At/T & A/T & 0 \end{array}

Position

At a fixed drive target, the solver linearizes F about the current position estimate qk. Setting that approximation to zero gives the Newton correction. The desktop solver computes the correction by least squares, which also handles redundant constraints.

F(qk+Δq,t)≈Fk+JkΔq,Δqk=arg min⁡d ∥Jkd+Fk∥2,qk+1=qk+λ Δqk. \begin{gathered} \boldsymbol{F}(\boldsymbol{q}_k+\Delta\boldsymbol{q},t) \approx \boldsymbol{F}_k+J_k\Delta\boldsymbol{q},\\ \Delta\boldsymbol{q}_k =\underset{\boldsymbol{d}}{\operatorname{arg\,min}}\, \lVert J_k\boldsymbol{d}+\boldsymbol{F}_k\rVert_2,\\ \boldsymbol{q}_{k+1}=\boldsymbol{q}_k+\lambda\,\Delta\boldsymbol{q}_k. \end{gathered}

The program tests a full step first, then halves λ until the residual norm decreases. It checks both the residual and the correction against the position tolerance. The solver starts at the static assembly and subdivides changes in drive displacement as needed to stay on the same assembly branch.

For the solved pose, a reduced singular value decomposition gives the linear solve used for derivatives. With full column rank, the condition number is the ratio of the largest to the smallest singular value. The rank check counts singular values above 10−7 times the largest. Too few independent constraints or a near-singular pose stops the solve.

J=UΣVT,J+=VΣ−1UT,κ2(J)=σmax⁡σmin⁡. \begin{aligned} J&=U\Sigma V^{\mathsf T},\\ J^+&=V\Sigma^{-1}U^{\mathsf T},\\ \kappa_2(J)&=\frac{\sigma_{\max}}{\sigma_{\min}}. \end{aligned}

Velocity and acceleration

Because the constraints hold along the path, both time derivatives of F vanish. The first derivative gives the velocity system. The product rule then gives the acceleration system, with an extra term from the changing Jacobian.

F˙=Jq˙−Bu˙=0,Jq˙=Bu˙,F¨=Jq¨+J˙q˙−Bu¨=0,Jq¨=Bu¨−J˙q˙. \begin{aligned} \dot{\boldsymbol{F}}&=J\dot{\boldsymbol{q}}-B\dot{\boldsymbol{u}} =\boldsymbol{0},\\ J\dot{\boldsymbol{q}}&=B\dot{\boldsymbol{u}},\\[3pt] \ddot{\boldsymbol{F}}&=J\ddot{\boldsymbol{q}}+\dot{J}\dot{\boldsymbol{q}} -B\ddot{\boldsymbol{u}}=\boldsymbol{0},\\ J\ddot{\boldsymbol{q}}&=B\ddot{\boldsymbol{u}} -\dot{J}\dot{\boldsymbol{q}}. \end{aligned}

When the link endpoints have relative velocity vB − vA, the link row contributes a squared-speed term to the acceleration right-hand side. The attachment row follows from differentiating e × f twice. The mixed product of the two anchor velocities has a factor of two.

(−J˙q˙)link=−∥vB−vA∥2L,(−J˙q˙)attach=2c(e˙×f˙),(−J˙q˙)drive=0. \begin{aligned} (-\dot{J}\dot{\boldsymbol{q}})_{\mathrm{link}} &=-\frac{\lVert\boldsymbol{v}_B-\boldsymbol{v}_A\rVert^2}{L},\\ (-\dot{J}\dot{\boldsymbol{q}})_{\mathrm{attach}} &=2c\bigl(\dot{\boldsymbol{e}}\times\dot{\boldsymbol{f}}\bigr),\\ (-\dot{J}\dot{\boldsymbol{q}})_{\mathrm{drive}} &=0. \end{aligned}

The solver computes these terms directly from the velocities and reuses the same Jacobian factorization for the acceleration solve. It then checks that each solution satisfies the differentiated constraints, which matters when several rows constrain the same motion.

Worked example

Consider one link of length L pinned to the origin. Its free end moves in the XZ plane and starts at (L, 0). The drive sets its height to u(t). With unknown absolute coordinates x and z, the position residual and its Jacobian are

F=[(x2+z2−L2)/(2L)z−u(t)],J=[x/Lz/L01]. \begin{aligned} \boldsymbol{F}&=\begin{bmatrix}(x^2+z^2-L^2)/(2L)\\ z-u(t)\end{bmatrix},\\ J&=\begin{bmatrix}x/L&z/L\\ 0&1\end{bmatrix}. \end{aligned}

On the branch starting at x = L, substituting z = u into the differentiated link equation gives the position, velocity, and acceleration below. The same quantities come from applying the two Jacobian systems.

x=L2−u2,z=u,x˙=−uu˙x,z˙=u˙,x¨=−uu¨+u˙ 2+x˙ 2x,z¨=u¨. \begin{aligned} x&=\sqrt{L^2-u^2}, & z&=u,\\ \dot{x}&=-\frac{u\dot{u}}{x}, & \dot{z}&=\dot{u},\\ \ddot{x}&=-\frac{u\ddot{u}+\dot{u}^{\,2}+\dot{x}^{\,2}}{x}, & \ddot{z}&=\ddot{u}. \end{aligned}

A 100 mm link lifted 60 mm has x = 80 mm. If the height is increasing at 10 mm/s with zero vertical acceleration, the horizontal speed is −7.5 mm/s and the horizontal acceleration is about −1.95 mm/s². The horizontal acceleration comes from the link’s changing orientation. At x = 0, the link reaches its vertical limit and the Jacobian loses rank.

Reading results

Points
Position is absolute XYZ. Displacement is relative to the static hardpoint. The interface shows lengths in mm and time derivatives in mm/s and mm/s². The point_kinematics.csv download uses m, m/s, and m/s².
Rods
The axis r points from A to B. Azimuth is measured from +X toward +Y and elevation is positive above the XY plane. The angular velocity and acceleration of that axis are
ω=r×r˙∥r∥2,α=r×r¨∥r∥2−2 r⋅r˙∥r∥2ω. \begin{aligned} \boldsymbol{\omega}&=\frac{\boldsymbol{r}\times\dot{\boldsymbol{r}}}{\lVert\boldsymbol{r}\rVert^2},\\ \boldsymbol{\alpha}&=\frac{\boldsymbol{r}\times\ddot{\boldsymbol{r}}}{\lVert\boldsymbol{r}\rVert^2} -\frac{2\,\boldsymbol{r}\cdot\dot{\boldsymbol{r}}}{\lVert\boldsymbol{r}\rVert^2}\boldsymbol{\omega}. \end{aligned}

Measuring spin around the axis requires another orientation reference. The rod_kinematics.csv download uses degrees for angles and radians for angular derivatives.

Rod interference
After a time-history solve, the lab compares modeled rod centerlines at each solved sample with a 0.01 mm tolerance. It skips shared joints and construction links. A warning lists the affected rod pairs and times. Choose Inspect to view the first affected sample in 3D. The check represents each rod as a line segment, so its findings depend on the model and the chosen sampling interval.
Damper histories
Let ℓ be the current length and ℓ0 the static length. Positive compression cd means the member is shorter than at the reference pose. Positive compression velocity means it is shortening. With axis unit vector n and endpoint relative velocity v = ṙ, the solver uses
n=r/ℓ,cd=ℓ0−ℓ,c˙d=−n⋅v,v⊥=v−(n⋅v)n,c¨d=−n⋅r¨−∥v⊥∥2ℓ. \begin{aligned} \boldsymbol{n}&=\boldsymbol{r}/\ell,\\ c_d&=\ell_0-\ell,\\ \dot{c}_d&=-\boldsymbol{n}\cdot\boldsymbol{v},\\ \boldsymbol{v}_\perp&=\boldsymbol{v}-(\boldsymbol{n}\cdot\boldsymbol{v})\boldsymbol{n},\\ \ddot{c}_d&=-\boldsymbol{n}\cdot\ddot{\boldsymbol{r}} -\frac{\lVert\boldsymbol{v}_\perp\rVert^2}{\ell}. \end{aligned}

The last acceleration term comes from the axis changing direction. Use damper_kinematics.csv to export these histories.

Motion ratio
The tool normalizes each measurement direction and projects the corresponding point displacement onto it. Reported displacements start at the first solved sample. For the tangent, choose the time path or one independent drive with the other drives held fixed.
si(t)=di⋅(pi(t)−pi(t0)),ratio⁡=dsout/dξdsin/dξ,MA⁡ideal=∣dsin/dξdsout/dξ∣,ξ=t or uj. \begin{aligned} s_i(t)&=\boldsymbol{d}_i\cdot(\boldsymbol{p}_i(t)-\boldsymbol{p}_i(t_0)),\\ \operatorname{ratio}&=\frac{ds_{\mathrm{out}}/d\xi}{ds_{\mathrm{in}}/d\xi},\\ \operatorname{MA}_{\mathrm{ideal}}&= \left|\frac{ds_{\mathrm{in}}/d\xi}{ds_{\mathrm{out}}/d\xi}\right|, \qquad \xi=t\ \text{or}\ u_j. \end{aligned}

For a selected drive uj, the solver extracts column j of the sensitivity matrix. The same Jacobian used for velocity yields this matrix by solving all the unit-input columns of B.

S=∂q∂u,JS=B,S=J+B S=\frac{\partial\boldsymbol{q}}{\partial\boldsymbol{u}}, \qquad JS=B, \qquad S=J^+B

A zero denominator leaves the corresponding ratio blank. An incompatible independent drive direction also produces a blank. The motion_ratio.csv export records a per-sample status.

Suspension sweeps

Single-wheel travel
Sweep one wheel through bump and droop with other wheel drives held at zero. Steered front corners can compare up to three fixed rack positions. Toe-in and top-out camber are positive. Let z be the wheel travel, s the rack position, τ the toe angle, and γ the camber angle. The rate curves use Jacobian sensitivities with rack position held fixed, reported in °/mm.
bump steer⁡(z,s)=τ(z,s)−τ(0,s),camber gain⁡=∂γ∂z∣s,bump steer rate⁡=∂τ∂z∣s. \begin{aligned} \operatorname{bump\,steer}(z,s)&=\tau(z,s)-\tau(0,s),\\ \operatorname{camber\,gain}&=\left.\frac{\partial\gamma}{\partial z}\right|_s,\\ \operatorname{bump\,steer\,rate}&=\left.\frac{\partial\tau}{\partial z}\right|_s. \end{aligned}

Track is the Y spacing across the axle, and wheelbase is the X spacing along the side.

Front axle steering
The rack sweeps at a fixed mean front heave H and roll angle R. Static track is T. Relative steer is measured against zero rack at the same pose, positive toward the left.
zleft=H+T2tan⁡R,zright=H−T2tan⁡R. \begin{aligned} z_{\mathrm{left}}&=H+\frac{T}{2}\tan R,\\ z_{\mathrm{right}}&=H-\frac{T}{2}\tan R. \end{aligned}

With wheelbase W, the Ackermann percentage uses the magnitudes of the outer and inner steering angles. Ideal Ackermann is 100% and parallel steering is 0%. With front-only hardpoints, enter the wheelbase to calculate this percentage.

100 WT(cot⁡∣θouter∣−cot⁡∣θinner∣) 100\,\frac{W}{T}\left(\cot|\theta_{\mathrm{outer}}|-\cot|\theta_{\mathrm{inner}}|\right)
Damper ROLL / HEAVE
The damper sweep uses a heave H equal to the sum of the two wheel travels. Its roll input R is left minus right wheel travel in mm. For a ROLL sweep the tool compares the compression of each damper at opposite, equal-magnitude roll inputs.
zleft=(H+R)/2,zright=(H−R)/2,difference⁡ %=100 ∣∣c+∣−∣c−∣∣(∣c+∣+∣c−∣)/2. \begin{aligned} z_{\mathrm{left}}&=(H+R)/2,\\ z_{\mathrm{right}}&=(H-R)/2,\\ \operatorname{difference}\ \%&= 100\,\frac{\bigl||c_+|-|c_-|\bigr|}{(|c_+|+|c_-|)/2}. \end{aligned}

The difference is set to zero when both compression magnitudes are effectively zero.
